# UnitTest140

Este projeto foi desenvolvido com o objetivo de praticar o uso de testes unitários em Python, utilizando a biblioteca `unittest` e o framework `pytest`. O projeto inclui exemplos de funções, utilitários e testes automatizados para garantir a qualidade e o correto funcionamento do código.

## Estrutura do Projeto

- `unitest/`: Contém o código principal do projeto.
- `utils/`: Funções utilitárias utilizadas pelo projeto.
- `__tests__/`: Scripts de testes automatizados.
- `fixtures/`: Arquivos de dados para testes (ex: CSVs).

## Ferramentas Utilizadas

- **Python 3.12**: Linguagem principal do projeto.
- **unittest**: Biblioteca padrão do Python para testes unitários.
- **pytest**: Framework para execução e organização dos testes.

## Como rodar localmente

1. **Clone o repositório:**

```powershell
git clone https://github.com/souza-vitor/UnitTest140.git
cd UnitTest140
```

2. **(Opcional) Crie e ative um ambiente virtual:**

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

3. **Instale o pytest:**

```powershell
pip install pytest
```

4. **Execute os testes:**

```powershell
pytest
```

Os testes serão executados automaticamente e você verá o resultado no terminal.
